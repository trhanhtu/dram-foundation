# Ti/TiN Sputter Target Conditioning & Vacuum Base Pressure Qualification SOP

- **Date**: 2026-10-12
- **Source**: Agent (Domain Expert AI)
- **Status**: Implemented

## Overview & Rationale
Actionable standard operating procedure for vacuum qualification and DC magnetron pre-sputter conditioning of Ti/TiN barrier and adhesion sputtering targets in 180nm DRAM metallization. Prevents oxygen incorporation and cross-contamination prior to active production deposition.

## Key Baseline Metric Limits
- **Vacuum Base Pressure**: $< 2.0 \times 10^{-6}\text{ Torr}$
- **Process Gas Purity**: $99.999\%$ (5N) Argon
- **Working Sputter Pressure**: $3 \text{ to } 5\text{ mTorr}$
- **DC Magnetron Power Setting**: $1.5 \text{ to } 3.0\text{ kW}$
