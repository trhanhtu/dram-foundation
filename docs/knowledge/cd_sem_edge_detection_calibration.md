- **Date**: 2026-10-15
- **Source**: Agent (Domain Expert AI)
- **Status**: Implemented

- **Target Node**: 180nm Open-Source DRAM (DRAM Foundation VN)

## Overview & Rationale
Defines the standard procedure for calibrating secondary-electron (SE) waveform edge-detection algorithms on Critical Dimension Scanning Electron Microscopes (CD-SEM) for 180nm DRAM access gates, active diffusion, contact holes, and overlay verification.

## Key Operational Parameters
- **Grid Resolution**: 0.005 um (5 nm placement grid).
- **Access Transistor Target**: L = 180 nm, W = 220 nm.
- **Contact Hole Target**: 0.17 um x 0.17 um (170 nm).
- **Overlay Budget**: Gate poly to active diffusion <= 35 nm.
