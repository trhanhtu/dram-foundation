# SOP: Wafer-Level March C- Algorithmic Execution & Shmoo Margin Characterization

- **Date**: 2026-10-15
- **Source**: DRAM Foundation VN Council (Gen 3 - 180nm)
- **Status**: Implemented

## Overview & Rationale
Execution protocol for automated wafer-level Electrical Die Sort (EDS) parametric testing, March C- array fault detection, and 2D Shmoo margin characterization across voltage and timing spaces for 180nm 1T1C stacked capacitor DRAM architectures.

## Key Details / Architecture
Integrated probe sequence covering DC continuity, 10N March C- pattern execution, Shmoo voltage/timing envelope exploration, and fail bitmapping (FBM).
