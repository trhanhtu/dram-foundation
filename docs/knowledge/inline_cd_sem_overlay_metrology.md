# In-Line CD-SEM Gate Profile Characterization & Poly-to-Active Overlay Error Metrology

- **Date**: 2026-10-15
- **Source**: Agent
- **Status**: Accepted

## Overview & Rationale
Standard Operating Procedure (SOP) governing non-destructive automated in-line CD-SEM (Critical Dimension Scanning Electron Microscopy) gate profile measurement and optical/SEM overlay registration between the patterned polysilicon gate layer and underlying active diffusion area for the 180nm DRAM cell architecture.

## Key Details / Architecture
- **Technology Node**: 180nm Open-Source DRAM (DRAM Foundation VN / SKY130 grid compatibility).
- **Gate CD Nominal Target**: 180 nm access transistor channel length ($L = 180\text{ nm}$); active diffusion width $W = 220\text{ nm}$; minimum poly spacing $210\text{ nm}$ ($0.21\ \mu\text{m}$).
- **Overlay Registration Tolerance**: Maximum permissible misalignment $\le 35\text{ nm}$ vector error ($3\sigma$).
- **Grid Resolution**: $5\text{ nm}$ ($0.005\ \mu\text{m}$) manufacturing grid compliance.
