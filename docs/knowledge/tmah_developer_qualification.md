# 2.38% TMAH Developer Solution & Surfactant Qualification Knowledge

- **Date**: 2026-10-15
- **Source**: User & Domain Literature Context
- **Status**: Accepted

## Overview & Rationale
Standardization and qualification of 2.38% (0.26N) Tetramethylammonium Hydroxide (TMAH) metal-ion-free developer solution and surfactant additives for 180nm critical dimension polysilicon gate patterning within DRAM Foundation VN / SkyWater SKY130 manufacturing lines.

## Key Details / Architecture
- **Target Chemistry**: 0.26N TMAH (e.g., Microposit MF-319 / AZ 726 MIF).
- **Bath Temperature**: 21.0°C ± 0.5°C.
- **Puddle Development Window**: 45 to 60 seconds.
- **Rinse Line Spec**: Overflow dump rinse with 18.2 MΩ·cm deionized water for 60 seconds followed by dry spin / filtered N2 dry.
- **CD Impact**: Ensures poly gate critical dimension control down to 150 nm - 180 nm target gates without unexposed resist loss or surfactant foaming defects.
