# AOI High-Resolution Telecentric Optics Calibration & Dicing Film Frame Fixturing Setup

- **Date**: 2026-10-15
- **Source**: Agent (Domain Expert AI - DRAM Foundation VN)
- **Status**: Implemented

## Overview & Rationale
This standard operating procedure establishes the physical fixturing, vacuum-clamping, telecentric optics distortion correction, and sub-pixel edge detection calibration for Automated Optical Inspection (AOI) tools monitoring wafer kerf quality, chipping, and micro-cracks following high-speed diamond saw dicing.

## Key Details / Architecture
- **Stage Alignment**: Automated mechanical registration into standard film frame chuck with multi-zone vacuum retention.
- **Optics & Illumination**: Bilateral telecentric lens calibration across Z-axis travel with balanced brightfield/darkfield illumination.
- **Metrology Tolerances**: Physical reference grid pegged to PDK lithography grid (5 nm) and Rayleigh resolution limits ($R = 152\text{ nm}$).
